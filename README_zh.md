# Refined Modal

为 Obsidian 的弹窗与右键菜单添加自然的进出场动画，搭配可调节的背景模糊与毛玻璃效果。

[English](README.md) · 简体中文

Refined Modal 是一款面向 **Obsidian 桌面端**的界面增强插件。你可以让弹窗轻轻放大、淡入，让右键菜单顺着展开方向滑入，也可以在弹窗打开时模糊后方界面，让当前内容更突出。动画的时长、缩放幅度和速度变化都能按自己的习惯调整。

## 主要功能

### 弹窗动画

为常规弹窗、命令面板和快速切换器等界面添加淡入、淡出与缩放过渡。打开和关闭时的动画可以分别设置：

- **时长**：控制动画持续多久。
- **尺寸**：控制打开时的起始大小，以及关闭时的结束大小。例如，入场起始尺寸设为 96%，弹窗就会从原始大小的 96% 放大到 100%。
- **缓动曲线（动画速度随时间的变化方式）**：决定动画是匀速进行，还是先快后慢等。

### 右键菜单动画

为右键菜单及其子菜单添加进出场过渡。菜单入场时的淡入、滑动与缩放可以分别设置时长，也可以调整滑动距离、起始尺寸，以及退场时长和结束尺寸。

一级菜单向上或向下展开时，插件会相应调整滑动方向和缩放起点。右键菜单动画有独立开关。

### 背景效果

弹窗打开时，可以调整后方界面的模糊、变暗程度、对比度、饱和度与缩放比例；关闭后，背景会恢复原状。背景进入和恢复的时长、缓动曲线可以分别设置。

如果只想突出弹窗，可以适当增加背景模糊或变暗程度；如果喜欢轻微的空间层次，也可以让背景略微缩小。

### 毛玻璃效果

为主窗口中的弹窗、命令面板、右键菜单和编辑器补全浮层添加半透明背景。可以独立调整模糊、亮度、对比度和饱和度，也可以选择是否保留主题原有的背景色。

开启「保留原背景色」后，「背景色不透明度」决定底色的浓淡：数值越高，底色越实；数值越低，背后的内容越明显。关闭此项后，仅保留模糊和滤镜效果。

**背景模糊与毛玻璃模糊是两项独立设置**：前者调整弹窗后方的界面，后者调整透过弹窗或菜单看到的背景。

## 设置与预览

在「设置 → Refined Modal」中调整效果。设置分为四个标签页，修改即时生效，并自动保存。

| 标签页 | 可调整的内容 |
| --- | --- |
| 背景 | 模糊、变暗程度、对比度、饱和度、缩放，以及背景进入和恢复的时长与曲线。 |
| 弹窗 | 入场与退场时长、起始与结束尺寸，以及对应的缓动曲线。 |
| 右键菜单 | 动画开关，淡入、滑动与缩放时长，滑动距离、尺寸，以及退场参数和缓动曲线。 |
| 毛玻璃 | 效果开关、原背景色及其不透明度，以及模糊、亮度、对比度和饱和度。 |

点击设置页上方的「打开预览」，可以查看弹窗入场效果；按 `Esc`、点击弹窗外部或「关闭」按钮，可以查看退场效果。调整参数后，再次打开预览即可比较变化。

缓动曲线可以使用预设，也可以选择「自定义」，输入 `cubic-bezier(...)`（三次贝塞尔曲线表达式）。不熟悉曲线时，保留默认值即可。

每项参数旁都有恢复默认按钮。页面底部的「重置全部参数」会在确认后恢复所有视觉与动画参数，保留语言选择。

界面支持简体中文、繁体中文、英文和日文，默认跟随 Obsidian，也可以在插件设置中手动选择。

## 使用建议与兼容性

- **从默认参数开始**：建议一次调整一类效果，再用预览比较。想减少缩放感，可以将入场起始尺寸和退场结束尺寸调到更接近 100%。
- **文字可读性**：如果毛玻璃背后的内容干扰阅读，可以开启「保留原背景色」，并提高背景色不透明度。
- **性能**：大面积模糊和毛玻璃可能增加渲染负担。如有卡顿，可以先关闭毛玻璃，或降低背景模糊半径。
- **主题与其他插件**：主题、CSS 片段（自定义样式）或其他插件可能同时修改弹窗与菜单的样式。若效果异常，可以暂时关闭相关样式或插件，排查是否存在冲突。
- **独立窗口**：毛玻璃效果仅应用于主窗口，不应用于独立弹出的窗口。设置页位于独立窗口时，预览弹窗可能仍在主窗口打开。
- **减少动态效果**：插件会响应系统的「减少动态效果」偏好，停用弹窗和菜单的进出场动画，并移除工作区背景的缩放、滤镜与过渡效果。
